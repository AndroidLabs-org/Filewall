Frequently Asked Questions

What is Filewall?

Filewall: Secure Storage Provider is an Android app that acts as a firewall for your files. It gives you full control over which apps can access specific files or folders on your device using Android's official Storage Access Framework (SAF).

Does Filewall encrypt my files?

No. Filewall does not use encryption. Instead, it relies on access control rules and Android’s SAF to restrict which apps can read, write, or list files within a designated secure storage area.

How does Filewall protect my files?

You define per-app rules to allow or deny read, write, or list access to folders selected via SAF. You can also set temporary access, block apps entirely, and receive notifications when an app tries to access protected data.

How do I allow subfolder creation in SAF?

Unlike a traditional file system, the Storage Access Framework (SAF) requires explicit permissions for each folder before you can create or modify it — even if that folder doesn’t yet exist. This means that having full permissions (without Extend permissions to subfolders enabled) for a parent folder does not automatically grant you the ability to create or change subfolders within it. In other words, folders inside a parent folder are treated independently from the files in that same parent folder. If you attempt to create a subfolder without first granting permissions to that specific folder, the operation will fail. Once permission is approved, repeating the action will succeed. As an alternative, you can temporarily enable Extend permissions to subfolders on the parent folder or temporarily disable filewall protections entirely (though this is not recommended unless the application needs to create complex dynamic filesystem structures during setup which would otherwise require multiple approvals that would break the app's initialization process). Note that a write permission on a folder is also permission to delete it: the folder goes along with all its subfolders and files, including items that have no rule of their own. A delete is checked against the item being deleted, not its parent, so deleting a subfolder that the parent's grant does not reach raises its own request first — unless Extend permissions to subfolders is on for the parent, in which case the app can delete it without being asked again.

What is Silence Mode?

Silence Mode allows you to use Filewall without interruptions. When enabled, Filewall will not display dialog boxes or notifications when an external app tries to access a protected folder. Access attempts are still enforced and logged silently.

How do I allow or deny access to a folder?

You can control access in two ways:

  • Reactive method: Open the folder from the external app. Filewall will log the request and display it in the Requests tab, where you can approve or deny it.
  • Manual method: Create a rule directly in Filewall by selecting the app and folder and defining the appropriate permissions (read, write, list, or block).
Why should I grant full permissions on first setup?

When selecting Filewall as a document provider for a new app—especially one that will write to the storage—it's recommended to initially grant all permissions, including Extend permissions to subfolders.

This ensures the app can complete setup operations like directory creation. Once initialized, you can safely reduce permissions according to your needs.

Does Filewall require root?

No. Filewall works entirely within Android’s standard APIs. No root or special device configuration is required.

Is my authentication data secure?

Filewall uses Android's Keystore system to securely store PIN and biometric authentication data. Your credentials never leave the device.

Does Filewall connect to the internet or send data?

No. Filewall does not require internet access and never collects or transmits any user data. Everything remains strictly on your device.

What kind of logs does Filewall keep?

Filewall keeps an access log locally on your device: attempts by apps to read, write, or list files, and whether each was allowed or denied. Access logging is optional and can be switched off in Settings. Changes you make to your rules are not logged.

Is Filewall safe for children?

Filewall is not intended for users under 13. It is a technical tool meant for users who understand Android’s file system and permission model.

Where is Filewall available?

Filewall is available globally through open-source Android platforms like F-Droid. There are no regional restrictions.

Is Filewall open source?

Yes! Filewall is fully open source and maintained by AndroidLabs. You can view the source code in our GitHub repository. Bug reports and suggestions are welcome as issues.
